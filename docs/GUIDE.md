# خزانة — دليل الاستعمال

**خزانة** أرشيف شخصي ذكي: ترمي فيه أي ورقة أو ملف، فيقرؤه Claude Opus 5.5 ويفهمه ويضعه في رفه، ويمنع تكراره، ثم تجده في ثوانٍ بأي تفصيل تتذكره.

---

## 1. ما بُني

| الميزة | ما تفعله |
|---|---|
| **الإضافة** | رفع ملفات أو مجلدات كاملة أو ZIP (PDF، صور، Word، نصوص)، أو «مشاركة ← خزانة» من الهاتف |
| **الماسح الذكي** | الكاميرا تكتشف حواف الورقة، تلتقط وحدها حين يثبت الهاتف، تقوّم الميلان، تزيل الظلال، تنبّه للصفحة الضبابية وتتجاهل البيضاء. أربعة أوضاع: وثيقة واحدة / رزمة مختلطة (يفصلها Claude) / بطاقة بوجهين / **هل عندي هذه؟** (صوّر ورقة في إدارة أو مكتبة فيقول لك إن كانت في خزانتك) |
| **القراءة والفهم** | Claude يقرأ الصفحات الممسوحة (العربية والفرنسية والإسبانية وخط اليد)، ويستخرج: النوع، العنوان، ملخصاً بالعربية، الأشخاص وأدوارهم (أستاذ، طبيب، مؤلف…)، الجهات، الأماكن، التواريخ، السنة الجامعية، تاريخ الانتهاء، الأرقام المرجعية، الحساسية، وكلمات بحث بأربع لغات |
| **الرفوف الجديدة** | إن لم يجد رفاً مناسباً **يقترح** رفاً جديداً (بالعربية والفرنسية والإسبانية والإنجليزية) ولا يُنشئه إلا بموافقتك. تبقى الوثيقة في الرف الأعلى حتى تقرر. وبعد الإنشاء يقترح نقل الوثائق القديمة المناسبة |
| **منع التكرار — 6 طبقات** | ① البصمة الرقمية قبل الرفع ② بصمة النص ③ البصمة البصرية لكل صفحة ④ تشابه النص ⑤ الجزء من وثيقة أطول ⑥ نفس الأرقام المرجعية بلغة أخرى (مثل الترجمة المحلفة). المطابق تماماً يذهب إلى السلة، والملتبس يُسأل عنه |
| **البحث** | يفهم اشتقاقات الكلمة (إدارة = الإداري = الإدارية)، والهمزات والتاء المربوطة، وأسماء الأشخاص بالعربية واللاتينية، والأخطاء الإملائية، وجملاً كاملة («محاضرات بنعلي في الإداري 2018»)، والبحث بالصوت. النتيجة تُفتح على الصفحة نفسها والكلمة مظللة |
| **صفحة لكل دكتور** | كل وثائقه عبر السنوات، مجالاته، ومن يرد معه |
| **أين الأصل؟** | صناديق وأماكن للأوراق الأصلية، ملصقات QR للطباعة، و«جلسة مسح» لكل صندوق |
| **Google Drive** | أرشيف واحد على الحاسوب والهاتف: الملفات في Drive الخاص بك، ومجلد «خزانة» مرئي فيه مجلد لكل رف، وكل ورقة ممسوحة ملف PDF. الفهرس على كل جهاز، فيعمل البحث دون إنترنت |
| **الخزنة** | الهوية والجواز والطبي والبنك تختفي من كل مكان حتى تفتحها ببصمتك أو برمز قفل الجهاز، ولا تظهر أبداً في مجلد «خزانة» المرئي |
| **التحميل** | الوثيقة الأصلية، أو ZIP لأي اختيار مرتب في مجلدات الرفوف مع فهرس |
| **الميزانية** | سقف شهري للتكلفة؛ تتوقف المعالجة عنده وتنتظر إذنك. وتتوقف أيضاً إن نفد رصيد حساب Claude، دون أن تضيع أي وثيقة |
| **النسخ الاحتياطي** | ملف ZIP واحد فيه كل البيانات وكل الملفات، والاسترجاع منه دون تكرار |

## 2. التشغيل على الحاسوب

```bash
cd khizana
npm install
npm run dev
```

ثم افتح `http://localhost:5177/khizana/`. كل شيء يُحفظ في المتصفح على هذا الجهاز (قاعدة بيانات Postgres حقيقية داخل المتصفح)، ثم في Google Drive بعد ربطه (الفقرة 5).

**أو دون أي تثبيت**: التطبيق منشور على **https://mykhizana.github.io/khizana/**، فافتحه من الحاسوب والهاتف معاً. المنشور هو الكود وحده؛ وثائقك تبقى على أجهزتك وفي Drive الخاص بك. ولكل عنوان نسخته في المتصفح: ما تضيفه في `localhost` لا يظهر في العنوان المنشور، والعكس، ويجمع Google Drive بينهما.

> قبل ربط Claude يعمل التطبيق «بتصنيف تقريبي»: قواعد بسيطة تُظهر كل الميزات، لكنه لا يقرأ الصور الممسوحة.

### ربط Claude Opus 5.5
1. ادخل إلى **console.anthropic.com** بالحساب الذي يظهر فيه رصيد API (إن كان لديك رصيد شهري مع اشتراكك، فالمفتاح يجب أن يُنشأ في الحساب نفسه؛ تحقق من الرصيد في **Billing**).
2. **Settings ← API Keys ← Create Key**، وانسخ المفتاح (يبدأ بـ `sk-ant-`).
3. في خزانة: **الإعدادات ← الذكاء الاصطناعي**، الصقه واضغط «حفظ واختبار». الصقه مرة في كل جهاز (الحاسوب والهاتف): لا يُرسل إلى Drive ولا إلى أي مكان غير Anthropic.
4. حدّد **السقف الشهري** على قدر رصيدك (مثلاً 100$ إن كان رصيدك الشهري 100$).

تُعاد قراءة الوثائق التي صُنفت تقريبياً تلقائياً بعد الربط. وإن نفد الرصيد تتوقف المعالجة وتنتظر، ثم تستأنف من حيث توقفت.

## 3. الاستعمال اليومي

- **أضف**: زر «أضف وثائق» ← «امسح بالكاميرا» أو «ارفع ملفات».
- **تحتاج قرارك**: الرفوف المقترحة (أنشئه / ضعها في رف موجود / لا تقترحه)، التكرارات المحتملة، الأشخاص الجدد، والتصنيفات غير المؤكدة. كل قرار يتعلمه التطبيق: الرف المرفوض لا يُقترح ثانية، والرف الذي تختاره بدلاً منه يُستعمل تلقائياً بعد ذلك.
- **صحّح** أي بطاقة من صفحة الوثيقة (تعديل البطاقة)؛ ما تصححه لا يغيّره الذكاء الاصطناعي أبداً.
- **الإعدادات ← الرفوف الجديدة**: «اسألني دائماً» (الافتراضي)، أو «الرئيسية فقط»، أو «تلقائياً».

---

## 4. خطة الرقمنة قبل السفر

1. اجمع الأوراق في صناديق أو ملفات مرقمة، دون ترتيب داخلها.
2. **أماكن الأصول الورقية ← مكان جديد** لكل صندوق، ثم **اطبع الملصقات** والصقها.
3. افتح **جلسة مسح** لكل صندوق: كل ما تمسحه يُسجَّل تلقائياً «الأصل: صندوق 3».
4. امسح بوضع **رزمة مختلطة** (هاتف وحامل بسيط، والالتقاط تلقائي): يفصل Claude الوثائق وحده.
5. ضع على الأصول التي ستأخذها مكاناً باسم «معي في إسبانيا».
6. انتبه إلى الصفحات المعلَّمة «ضبابية» وأعد تصويرها والأصول ما تزال بين يديك.
7. اربط **Google Drive** على الحاسوب والهاتف (الفقرة 5): كل ما تمسحه بالهاتف يصل إلى الحاسوب، والعكس.

## 5. Google Drive: أرشيفك على الهاتف والحاسوب

يستعمل مساحة Google One التي تدفع ثمنها، دون أي خادم أو اشتراك آخر.

**ما يحدث بعد الربط:**
- **مجلد «خزانة»** في Drive الخاص بك: مجلد لكل رف، وكل وثيقة باسم واضح («محاضرات القانون الإداري (2018/2019).pdf»)، والورقة الممسوحة ملف PDF واحد. تراه من تطبيق Drive، ويبقى لك مهما حدث. رتّب من خزانة لا من Drive: هذا المجلد صورة لرفوفك. ويمكن إيقافه من الإعدادات.
- **جزء مخفي** من Drive لا يراه غير التطبيق: الملفات الأصلية وصور الصفحات، والفهرس، وتغييرات كل جهاز. حتى لو حذفت شيئاً من مجلد «خزانة» بالخطأ، يبقى أصله هنا ويُعاد.
- **الفهرس على كل جهاز**: البحث يعمل دون إنترنت. والملف الذي لم يُفتح بعد على هذا الجهاز يُنزَّل من Drive عند فتحه، ويبقى عليه.
- التغييرات تصل إلى الجهاز الآخر خلال دقيقة تقريباً. وإن عدّلت الوثيقة نفسها على جهازين في اللحظة نفسها، يبقى آخر تعديل.
- **ساعة Google**: يعطي Google التطبيق إذناً لساعة. بعدها يظهر شريط «متابعة»: ضغطة واحدة. لا يضيع شيء في الأثناء، فكل ما تضيفه ينتظر على الجهاز.

### أ. معرّف Google (مرة واحدة، مجاناً، دون بطاقة دفع)
> **تمّ في 13 نوفمبر 2026**: مشروع **khizana** (`khizana-514621`) في Google Cloud، شاشة الإذن «خزانة» **منشورة** (En production) بالصلاحيتين وحدهما، والمعرّف «khizana web» مبني في التطبيق المنشور. فلا تحتاج لصق أي شيء: اذهب مباشرة إلى «ب». الخطوات أدناه للمرجع، أو لإعادة إنشائه. قد يتأخر Google من 5 دقائق إلى بضع ساعات في تطبيق الإعداد الجديد: إن رفض الدخول في البداية فأعد المحاولة لاحقاً.

1. افتح **console.cloud.google.com** بحسابك الذي فيه Google One، ثم **New project** (الاسم: khizana).
2. **APIs & Services ← Library**: ابحث عن **Google Drive API** ← **Enable**.
3. **Google Auth Platform** (أو **OAuth consent screen**) ← **Get started**:
   - App name: خزانة، والبريد: بريدك.
   - Audience: **External**.
   - في **Branding**: الصفحة الرئيسية `https://mykhizana.github.io/khizana/`، وصفحة الخصوصية `https://mykhizana.github.io/khizana/privacy.html`، والنطاق المأذون `mykhizana.github.io`. بدونها لا يقبل Google نشر التطبيق.
   - ثم في **Audience** اضغط **Publish app** (التطبيق لا يطلب إلا صلاحيتين بسيطتين، ودون شعار، فلا يحتاج مراجعة من Google).
4. **Data Access ← Add or remove scopes**: أضف `.../auth/drive.file` و`.../auth/drive.appdata` ← Save.
5. **Clients ← Create client** ← النوع **Web application**:
   - **Authorized JavaScript origins**: `https://mykhizana.github.io` (العنوان المنشور، دون مسار)، و`http://localhost:5177` إن أردت التجربة على الحاسوب.
   - **Authorized redirect URIs**: `https://mykhizana.github.io/khizana/`، و`http://localhost:5177/khizana/`.
   - **Create**، ثم انسخ **Client ID** (ينتهي بـ `apps.googleusercontent.com`). هذا المعرّف ليس سراً، ولا تحتاج «Client secret».
6. ضعه مرة واحدة في GitHub ليُبنى مع التطبيق فلا تلصقه في كل جهاز: **github.com/mykhizana/khizana ← Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**، الاسم `GOOGLE_CLIENT_ID` والقيمة المعرّف، ثم **Actions ← Test and deploy to GitHub Pages ← Run workflow**. (أو الصقه في **الإعدادات ← Google Drive** في كل جهاز.)

### ب. ربط الجهاز الأول (الحاسوب)
1. افتح **https://mykhizana.github.io/khizana/** في متصفحك المعتاد على الحاسوب، ثم **الإعدادات ← Google Drive ← اربط Google Drive** (المعرّف مبني في التطبيق).
2. في نافذة Google اختر حسابك، وفعّل **المربعين** (الملفات التي ينشئها التطبيق، وبياناته المخفية). إن ظهر «Google لم يتحقق من هذا التطبيق» فهو تطبيقك أنت: **متقدم ← الانتقال إلى خزانة**.
3. «إنشاء أرشيفك في Drive» ← **ابدأ**. يُرفع كل شيء في الخلفية، وترى العداد في الإعدادات.

### ج. ربط الهاتف
1. افتح **https://mykhizana.github.io/khizana/** على الهاتف (عنوان https: يشترطه Google للدخول)، ثم **الإعدادات ← Google Drive ← اربط**.
2. «وجدنا أرشيفك في Drive» ← **ابدأ**: يُنزَّل الفهرس، وتظهر كل وثائقك.
3. أضف التطبيق إلى الشاشة الرئيسية. على iPhone، إن لم تُفتح نافذة Google فاستعمل «الدخول بطريقة أخرى».
4. الصق مفتاح Claude في الهاتف أيضاً إن أردت أن يقرأ الهاتف ما تمسحه فوراً.

> إن كان على جهاز وثائق قبل ربطه بأرشيف موجود، يُدمج الاثنان دون تكرار، وتبقى إعدادات أرشيف Drive.

### د. أمور مفيدة
- **وفّر مساحة هذا الجهاز** (الإعدادات): تُحذف من الهاتف نسخ الملفات المحفوظة في Drive، وتبقى الصور المصغرة والوثائق المعلّمة «متاحة دون إنترنت».
- **افصل هذا الجهاز**: يتوقف التزامن، ويبقى الأرشيف عليه وفي Drive.
- فعّل **التحقق بخطوتين** في حساب Google: صار هو الحارس الأول لنسخة أرشيفك في Drive.

### بديل: Supabase (مدفوع)
يبقى في الكود وضع سحابي عبر Supabase Pro (حوالي 25$ شهرياً، في منظمة منفصلة عن مشاريعك الحالية)، بخادم يحفظ مفتاح Claude وتحقق ثنائي للخزنة. لا تحتاجه مع Drive.

## 6. الأمان

- **الخزنة**: الوثائق الحساسة تختفي من البحث والقوائم والأشخاص والآجال حتى تفتحها ببصمتك أو برمز قفل الجهاز (**الإعدادات ← الخزنة**). تُقفل وحدها إن بقي التطبيق في الخلفية 5 دقائق. ولا تُنسخ أبداً إلى مجلد «خزانة» المرئي: تبقى في الجزء المخفي من Drive. وإن نقلتَ وثيقة إلى الخزنة بعد نسخها، تُحذف نسختها المرئية نهائياً (لا إلى سلة Drive).
- **عنوان خاص بخزانة وحدها**: `mykhizana.github.io` (منظمة GitHub مجانية خاصة بها، فيها مستودع الكود `github.com/mykhizana/khizana`). المتصفح يجعل كل ما تحت عنوان واحد تطبيقاً واحداً، فلا يُنشر تحت هذا العنوان أي موقع آخر (لا Sweet House ولا Bella ولا أي كود إعلانات): ما تحفظه خزانة في المتصفح لا يصل إليه كود موقع آخر.
- لا يدخل التطبيق إلا ما أنشأه هو في Drive: لا يرى ملفاتك الأخرى أبداً (صلاحية «الملفات التي ينشئها التطبيق» فقط).
- مفتاح Claude يبقى على كل جهاز، ولا يُرسل إلا إلى Anthropic. وإذن Google يُحفظ ساعة واحدة فقط.
- بيانات Anthropic API التجارية لا تُستعمل لتدريب النماذج.
- لا يُحذف شيء نهائياً إلا من سلة المحذوفات بأمرك. حتى النسخة الثانية من الملف نفسه تذهب إلى السلة.
- لا تُعالَج الوثيقة الواحدة مرتين: كل جهاز يعالج ما أضافه، وكل وثيقة تُحجز قبل معالجتها.

## 7. التكلفة التقريبية

- **Claude Opus 5.5** (الأدق): 4$ لكل مليون رمز مدخل، و20$ لكل مليون رمز مخرج.
- **Claude Sonnet 5.5**: نصف ذلك بالضبط، 2$ و10$.
- مع Opus: فهم وتصنيف وثيقة (رقمية أو ممسوحة) حوالي 5 إلى 8 سنتات، وقراءة صفحة ممسوحة حوالي 4 سنتات. أي أن ورقة ممسوحة من صفحة واحدة تكلف نحو 10 سنتات، وملف من 5 صفحات نحو 25 سنتاً. ومع Sonnet النصف.
- مثال: 1000 وثيقة (نحو 3000 صفحة) تكلف قرابة 185$ مع Opus، ونحو 90$ مع Sonnet.
- Google Drive: لا تكلفة إضافية (مساحة Google One). الورقة الممسوحة تأخذ حوالي 0.6 ميغابايت مع نسختها المقروءة.

### من يقرأ وثائقك (الإعدادات)
- **تلقائي** (الافتراضي، وينصح به): الوثيقة الواحدة وبضع الوثائق يقرؤها Opus 5.5. والاستيراد الكبير، أي 5 وثائق فأكثر في الانتظار، يقرؤه Sonnet 5.5 بنصف الثمن، إلى أن تنتهي الوثائق المنتظرة كلها. النتيجة فورية في الحالتين.
- **Opus 5.5 دائماً**: الأدق في كل شيء، بالسعر الكامل. **Sonnet 5.5 دائماً**: نصف الثمن في كل شيء.
- البحث يبقى مع Opus دائماً، وكذلك «أعد القراءة والفهم» من صفحة الوثيقة.
- ما يرفضه Sonnet يقرؤه Opus تلقائياً. وإن لم يصل مفتاحك إلى Sonnet، يقرأ Opus كل شيء وتظهر ملاحظة في الإعدادات.
- وثيقة قرأها Sonnet ولم تعجبك قراءتها (خط يد، ختم باهت): افتحها ← ⋮ ← **«اقرأ الصفحات من جديد بـ Opus 5.5»**. يبقى نصها الحالي قابلاً للبحث حتى تُستبدل القراءة الجديدة به.
- لماذا لا «دفعات» (Batch) بنصف الثمن أيضاً؟ خدمة الدفعات في Anthropic لا تقبل الطلبات الآتية من صفحة ويب مباشرة: ترد بـ «Disallowed CORS origin»، أي أنها ترفض الطلبات القادمة من المواقع. وخزانة تعمل كلها في المتصفح. فتحتاج الدفعات وسيطاً صغيراً على خادم، ويمكن إضافته لاحقاً، فتصير التكلفة مع Sonnet نحو الربع.

## 8. الفحوص التقنية

```bash
npm run test:db     # قاعدة البيانات والأمان، ومنها سيناريوهات الاختراق (113 فحصاً)
npm run test:lib    # التطبيع، البصمات، اكتشاف الورقة، قرارات التكرار، واختيار Opus أو Sonnet (79 فحصاً)
npm run test:sync   # التزامن بين جهازين وثلاثة في قاعدة البيانات، ومنه حالات المراجعة المستقلة (75 فحصاً)
npm run test:drive  # محرك Drive كاملاً مع نسخة تجريبية من Google Drive (58 فحصاً)
npm run build
```

وتُشغَّل هذه الفحوص كلها في GitHub قبل كل نشر (`.github/workflows/deploy.yml`): إن فشل واحد منها لا يُنشر شيء، ويبقى العنوان على النسخة السابقة.

تجربة جهازين على الحاسوب دون حساب Google: `npm run fake-drive`، ثم `npx vite --mode fakedrive --port 5181` و`--port 5182` (ملف `.env.fakedrive`: `VITE_DRIVE_API=http://127.0.0.1:5199` و`VITE_DRIVE_FAKE=1`).

## 9. المراحل القادمة

- **اختياري**: دفعات Batch عبر وسيط صغير على خادم، إن كثرت الوثائق جداً: نصف ثمن آخر فوق Sonnet، والنتيجة بعد دقائق أو ساعات.

- **المرحلة 3**: كاشف النواقص، مساعد البحث العلمي (المراجع بصيغتك وفهرس النصوص القانونية)، بريد الأرشيف، الخريطة وشبكة العلاقات.
